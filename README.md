# Serenitée — sitio web

Sitio estático de Serenitée (pastelería artesanal, Martínez, San Isidro).

- `index.html` — página completa (carta, carrito y pedido por WhatsApp). El catálogo y precios están en los arrays `CATALOGO` e `INDIVIDUALES` dentro del `<script>` al final del archivo.
- `img/` — fotos de productos (800×1000, JPG).

Deploy automático en Vercel en cada push a `main`.
